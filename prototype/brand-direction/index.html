quick-start.tszero-install core
import { openai } from '@ai-sdk/openai';
import { Agent } from '@balsa/core/agent';

const agent = new Agent({
  name: 'assistant',
  instructions: 'You are concise.',
  model: openai.chat('gpt-4o-mini'),
  tools: { weather },  // plain-object tools
});

const result = agent.stream('Weather in Paris?');
for await (const chunk of result) process.stdout.write(chunk.text ?? '');

Compose only what you use

Five capability surfaces, each an opt-in package — nothing loads you don't ask for.
@balsa/core/agent · @balsa/ai-sdk
Plain-object tools with Standard Schema validation. One run, two consumption styles on the same object: for await streams Balsa's own chunk protocol; terminal values are awaited on it. Any AI SDK provider drops straight in. Wrap an agent as a tool on another agent — delegation is an ordinary tool call.
@balsa/core/workflow
Durable steps with JSON snapshots at step boundaries. A workflow suspends and resumes from another process — the snapshot is the contract.
@balsa/core · @balsa/croner
The documentation name for durable agents, signals, and schedules. Approval-listed tool calls suspend the run as a human approval gate; resume({ approved }) continues it.
@balsa/core/memory · @balsa/sqlite
Thread and resource identity plus message history, with opt-in resource-scoped working memory. SQLite adapter ships as a capability package.
@balsa/mcp-server · @balsa/mcp-client
Serve an agent as an MCP server; call MCP tools from an agent. Both directions, two packages.
